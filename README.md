# nonoka TTS：角色声线制作（GPT-SoVITS）

用游戏角色「nonoka」的语音数据，微调 GPT-SoVITS，让她能说日语和中文。个人非商用。

更新：2026-10-22（6.2 方法 3：合成中文数据训练 GPT，中文改用 `nonoka_mix` e2，见 5.8）

---

## 0. 当前方向

- **2026-10-22 决定：放弃 SBV2，也放弃零样本模型（Sarashina2.2-TTS、Qwen3-TTS），后面专注用全量数据微调 GPT-SoVITS，并优化中文效果。**
- 理由：SBV2 JP-Extra 只能说日语，零样本模型的音色不够像。GPT-SoVITS 是唯一一个音色像、又能说中文的方案。日语朗读的稳定性目前还不如 SBV2，要靠全量数据和调参来补。
- 第一轮（SBV2、零样本对照、评测方法的摸索）的完整记录、数据和脚本都在 `99_archive/2026-10-22_round1/`，说明见其中的 `README_round1.md`。
- **当前状态（2026-10-22）**：SoVITS 两种语言共用 `nonoka_full` e10。**GPT 按语言分开**：日语用 `nonoka_full` e6，默认 `aux2_ref4690`（5.4）；中文用 `nonoka_mix` e2（日语原声 + 合成中文一起训练的 GPT，5.8），默认 `aux3_zr04`，即一条转换后的、不在测试句里的中文当参考音频，再融合 3 条日语原声（5.7）。
- **下次从这里继续**：6.2 方法 3 已做完（5.8），中文小幅提升，日语继续用原来的 GPT。下一步是推理部署：**2026-10-22 决定不做本地推理，改为云端推理**。Modal 上已经有一个试用接口（6.4），正式方案到时再定。部署内容是一个 SoVITS、两个 GPT，按语言切换 GPT 权重和参考音频。

## 2. 数据

### 2.1 数据概况
- 原始数据共 639 条 ogg（48kHz 单声道，7 到 28.6 秒）。
- 录音质量很好：没有削波，停顿处是数字静音，**不需要降噪**。
- 语气起伏大：音高中位数在 215 到 552Hz 之间，有不少情绪化的台词。
- **031 系列（134 条）是亲密场景台词**，喘息、拖长音、含糊发音很多，转写也最不稳定（会被识别成「ご視聴ありがとうございました」之类的幻觉文本）。不适合朗读型训练，**整体排除**。

### 2.2 第一轮数据集（`02_dataset_v1/`，90 条，约 16 分钟）
- 自动筛选（→ `01_select/scores.csv`）：每条音频算了时长、响度、削波、静音、停顿、噪音、频谱重心、高频能量、音高等指标。时长不在 7–15 秒、或任一指标在分布两端的都排除，剩 190 条。再按"风格接近中位数"在 7–9、9–11、11–13、13–15 秒四段各取 25 条，排除其中 10 条 031 系列，得到 90 条。
- 转写（`03_asr/`）：Whisper large-v3 为主，kotoba-whisper v2.0 对照。large-v3 明显更好，有标点，人名也正确（「奏先輩」「夜月先輩」）。两边结果转成平假名比较相似度，标出可疑条目。坑：新版 PyAV 和 faster-whisper 不兼容，改用 soundfile 读音频、scipy 重采样。
- 人工校对（→ `esd.list`）：90 条全部确认，改了 6 条（比如「長者に」→「上手に」、「適常視察」→「敵情視察」），复核又修正 2 处。原则：文本和实际读音一致，口吃和重复按实际发音保留。
- 格式：`03000330.wav|nonoka|JP|文本`（沿用 SBV2 格式）。`train_gptsovits.py` 会自动转成 GPT-SoVITS 的格式，并把 ogg 转成 wav。

## 3. GPT-SoVITS 微调（`04_train/`）

### 3.1 配置
| 项目 | 设置 |
|---|---|
| 框架 | GPT-SoVITS，固定在 commit `b4570b8`（2026-10-19） |
| 版本 | **v2ProPlus**：官方说明效果超过 v4，而且学的是整个训练集的音色（v3/v4 更偏向参考音频）。V5 在 2026-10-05 才发布，主打不微调就有高相似度，微调流程还新，暂不用 |
| 环境 | Python 3.11，PyTorch 2.7.0（CUDA 12.8），L40S |
| 训练 | 第一轮：SoVITS 8 轮、GPT 15 轮。全量：SoVITS 10 轮（每 2 轮保存）、GPT 15 轮（每 3 轮保存）。batch 8 |
| 推理 | 参考音频 03002860（GPT-SoVITS 要求 3–10 秒），日语用 `all_ja`，中文用 `all_zh`，按标点切句（cut5），固定种子 |
| 试听 | 日语 `out/samples/` 是 5.8 的 5 个版本，中文 `out/zh/samples/` 是 5.8 的 6 个版本；之前的版本在 `out/round*/`。GPT-SoVITS 输出 32kHz，Seed-VC 输出 22.05kHz |
| 人名 | 训练文本和日语测试句里的「奏先輩」「夜月先輩」「十和先輩」（及假名写法）在上传前自动换成「カナデ」「ヨルツキ」「トワ」，避免 G2P 读错（`train_gptsovits.py` 的 `NAMES`）。esd.list 保留汉字 |

### 3.2 运行
1. 双击 `1_train.bat`：上传 `02_dataset_full` → 预处理 → 训练 → 生成日语和中文试听，存到 `out/`。以 `--detach` 运行，关掉窗口云端也会继续，但窗口要开着才能收到试听文件；没收到的话运行 `2_render.bat` 重新生成即可。第一次构建镜像要 15–20 分钟，之后用缓存。
2. 训练加试听合计约 15 分钟 L40S 时间（约 $1.95/小时）。
3. 改了测试句或参考音频：运行 `2_render.bat`，不用重新训练。混合数据的 GPT（5.8）：`python -m modal run train_gptsovits.py::train_gpt_main`（只训 GPT，含渲染约 15 分钟 L40S），只重新渲染加 `--render-only`；渲染哪些版本在 `MIX_COMBOS` 里改。
4. 训练轮数、渲染组合和参考音频，改 `train_gptsovits.py` 开头的常量（`S2_EPOCHS`、`S1_EPOCHS`、`COMBOS`、`REF`）。`COMBOS` 的每一项是（SoVITS 轮数，GPT 轮数，参考音频，推理参数），每个版本可以用不同的参考音频和 temperature/top_k；参考音频必须是数据集里 3–10 秒的条目。推理参数里还可以写 `speed_factor`（文件夹名加 `_sp<×10>`）和 `aux`：[条目编号]（作为 `aux_ref_audio_paths` 融合多条参考的音色，文件夹名加 `_aux<条数>`）。只生成日语：`python -m modal run train_gptsovits.py::render_main --langs ja`（约 3 分钟）。默认用全量数据（实验名 `nonoka_full`）；加 `--dataset 02_dataset_v1` 用第一轮数据（实验名 `nonoka`）。两个实验的特征和权重在 Modal 存储上分开存放，互不覆盖。

### 3.3 踩过的坑（脚本里都已处理）
- WebUI 启动时会写一个 `users.pth`，把仓库内的模块目录加进 Python 路径；不走 WebUI 时要自己写，否则会报 `No module named 'text'`。
- 新加的 GPU 重采样代码用到了 `resampy`，但 `requirements.txt` 里没有列出来。
- `fast_langdetect` 要求它的缓存目录事先存在（官方整合包里自带）。
- Modal 会把每条 `run_commands` 转成一行 Dockerfile `RUN`，多行脚本要先编码。镜像最后有一段 CPU 冒烟测试，走一遍日语和中文的文本处理加重采样，这类问题会在构建阶段报出来，不用等到开 GPU。
- 同一个 `run_commands` 里加命令会让整层重新构建（十几分钟）。只是追加依赖的话，新开一层 `.pip_install(...)` 放在最后。
- `TTS_Config` 找不到权重文件时，会静默回退到官方底模。生成脚本在加载前会先确认文件存在。

## 4. 评估工具

### 4.1 结果页（`3_blind_test.bat`）
- 生成并打开 `out/blind.html`（日语）和 `out/zh/blind.html`（中文）。`samples/` 里的每个文件夹算一个版本。
- 2026-10-22 起不再人工打分，页面直接显示结果：顶部是汇总表（CER、Gemini 四项评分和平均、客观指标，原声作为基线），**按 Gemini 平均分从高到低排序**，每句话下的版本也按这个顺序排；每条试听下面有 Whisper 听写和 Gemini 点评。第一轮的盲听打分版本在 `out/round1_v1/` 里（页面的相对路径已经失效，只作留档）。
- 顶部有 3 条原声参考。快捷键：J/K 切换版本并播放，空格播放/暂停。
- **播放音量自动对齐**到同一响度：不同模型的输出响度不同，响的那个总会显得更好。

### 4.2 CER（`03_asr/run_cer.bat`）
- Whisper large-v3 把试听转写回文本，和原句比较。日语两边都转成平假名（数字先转汉字数字），汉字和假名写法不同不算错；中文用 `--zh`，逐字比较。
- 局限：Whisper 按上下文写汉字，多音字和アクセント的错误基本测不出来。pykakasi 给参考文本标的人名读音（「奏」そう、「夜月」よるがつ）本身就是错的，所以人名那句的日语 CER 没有意义。

### 4.3 客观指标（`03_asr/auto_eval.py`，CPU 即可）
- 运行：`03_asr\venv\Scripts\python auto_eval.py`（中文加参数 `..\04_train\out\zh\samples`）。venv 里已装 CPU 版 torch、speechbrain、speechmos、librosa。
- venv 重建（venv 不进 git，clone 后要先建）：Python 3.12，在 `03_asr` 下运行
  1. `python -m venv venv`
  2. `venv\Scripts\python -m pip install -r requirements.lock.txt`（和原环境的包版本完全一致）
  - 装不上时退回宽松版本：先跑一次 `run_transcribe.bat`（会自动建 venv 并装 Whisper），再 `venv\Scripts\python -m pip install torch torchaudio speechbrain speechmos librosa pykakasi`。
  - ECAPA 模型（`03_asr/models/`）首次运行 auto_eval 时自动下载。
- 指标：音色相似（SpeechBrain ECAPA，和 90 条原声的余弦相似度）、MOS（torchaudio SQUIM）、DNSMOS（杂音和音质）、音高起伏（半音）、语速（拍/秒）。90 条原声按同样方法评测，作为基线。
- 局限：SQUIM 和 DNSMOS 都先降到 16kHz，**听不出高频差异**（比如"发闷"）。MOS 模型用英语数据训练，只看相对高低。

### 4.4 Gemini 盲评（`04_train/gemini_judge.py`）
- 通过 Antigravity CLI（`agy -p`）调用 Gemini 3.8 Flash。每句话一次调用：给它 3 条原声和打乱顺序的所有版本，按四个维度打分并写中文点评，2 轮取平均，默认 4 路并发。中文：`--root out/zh --lang zh`。
- 所有音频会先统一到 -23 dBFS 再交给 Gemini。音频会上传到 Google（已确认可以，都是测试数据）。agy 的工具调用默认免确认，同时开启 `--sandbox` 限制终端；加 `--confirm` 关掉。
- 2026-10-22 起默认用 **低思考档 `gemini-3.8-flash-low`**（`gemini_proofread.py` 也是），10 路并发。high 档每次调用 2–4 分钟。不要在同一次比较里混用不同档位，分数不可比。
- **agy 有个人额度**：2026-10-22 用 high 档跑了约 60 次调用后报 429「Individual quota reached」，约 2 小时后重置。脚本遇到额度错误会立即停止；重跑会接着做没完成的调用（已完成的保留在 `gemini_judge.csv` 里），加 `--fresh` 从头开始。

## 5. 第一轮结果（90 条，2026-10-22）

**日语**

| | CER | 音色相似 | MOS | 音高起伏 | 语速（拍/秒） |
|---|---|---|---|---|---|
| 原声 | – | 0.846 | 3.93 | 3.68 st | 4.26 |
| gsv_s2e8_s1e10 | 1.9% | 0.849 | 3.95 | 2.96 st | 5.01 |
| gsv_s2e8_s1e15 | 1.5% | 0.843 | 3.93 | 3.08 st | 4.87 |

- 音色和原声持平，语速接近原声，语调偏平（音高起伏 3.0，原声 3.7）。
- Gemini（和 SBV2 放在一起盲评，音量对齐后）给 GPT-SoVITS 约 2.8 分，SBV2 是 3.5–3.9 分。问题集中在普通朗读句子：
  - 吞音、误读：「上着」读成「はぎ」，「生まれて」读成「ほまれて」，「買いました」读坏。
  - 停顿处有吸气声和破音，音高发抖。
  - 人名「奏」读成そう、「夜月」读成よるつき，「十分（十分钟）」读成じゅうぶん。
